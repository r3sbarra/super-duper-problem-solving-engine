## Reporting a Vulnerability

If you discover a potential security vulnerability in the Super-Duper-Problem-Solving-Engine, please do not open a public issue.

Instead, please report the vulnerability responsibly by emailing the project maintainers or by filing a private security advisory through GitHub's Security tab.

When reporting, please include:
- A clear description of the vulnerability.
- Steps or a minimal script to reproduce the issue.
- Potential impact on systems running the engine (e.g., code execution within the simulation sandbox).

We take security issues seriously and will respond promptly to investigate and release patches.
